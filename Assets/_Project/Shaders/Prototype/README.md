# Roman Dream — камера RomanLevel

Полноэкранный эффект для сцены `Assets/_Project/Scenes/RomanLevel.unity`: пиксельная фактура первого референса, холодные тени, тёплые света, мягкий bloom и плёночное зерно второго. Свет, геометрия и материалы окружения продолжают определять содержание кадра.

## Где настраивать

Откройте `RomanDream.mat`. Весь шейдер собран из стандартных узлов **URP Fullscreen Shader Graph**, без Custom Function, HLSL-вставок и зависимости от All in 1 Shader Nodes.

| Параметр | По умолчанию | Что меняет |
| --- | ---: | --- |
| Pixel Height | 400 | Виртуальная высота изображения. Ширина подстраивается под пропорции экрана. 240–320: более грубое ретро; 480–720: мягче и детальнее. |
| Pixel Amount | 1 | Сила привязки изображения к пиксельной сетке; 0 отключает пикселизацию. |
| Colour Steps | 32 | Число интервалов на цветовой канал. 12–24 усиливает постеризацию; 48–64 делает переходы плавнее. |
| Dither Strength | 0.65 | Статическое зерно на пиксельной сетке, смягчающее полосы постеризации. |
| Film Grain | 0.025 | Амплитуда анимированного монохромного зерна. |
| Grain Frames Per Second | 8 | Частота обновления зерна. 0 замораживает рисунок. |
| Effect Blend | 1 | Смешивание результата Shader Graph с входным кадром. 0 отключает только обработку графом, сохраняя Volume. |

`RomanDreamVolume.asset` управляет цветом и свечением: Neutral Tonemapping, Bloom, Color Adjustments, White Balance, Split Toning и Vignette. Neutral сохраняет детали тёмных коридоров. Для более сказочного вида поднимите Bloom Intensity/Scatter; для более сурового ретро уменьшите Bloom и Pixel Height. Motion Blur и глубина резкости не используются.

## Как подключено

`Main Camera` рисует мир → `HandsCamera` добавляет руки → Volume обрабатывает общий кадр → `RomanDreamRenderer` запускает граф после постобработки. Обычный экранный UI отрисовывается отдельно. Граф читает **BlitSource**, поэтому включает прозрачные объекты и воду; Scene Color/opaque texture для этого эффекта не используется.

Выбор рендера и настройки камер сохранены как переопределения экземпляра Player **только в RomanLevel**. Общие префабы не изменены. В PC/Mobile URP assets добавлена регистрация рендера под индексом 1; исходные рендеры под индексом 0 остаются стандартными. В эффекте нет runtime-скриптов. Рендер выбран на последней камере: при изменении стека камер назначьте его новой последней камере, иначе эффект будет применён раньше новых слоёв.

Чтобы вернуть прежние настройки RomanLevel:

1. На `Player/HandsCamera`: Renderer → Use Pipeline Settings, Volume Mask → Nothing, Volume Trigger → None; Post Processing оставить включённым.
2. На `Player/Main Camera`: включить Post Processing.
3. На `Global Volume`: вернуть `Assets/Settings/SampleSceneProfile.asset`.

Shader Graph Preview не содержит реального кадра камеры; результат проверяйте в Game View, в том числе в Play Mode.

## Пиксельный свет одного факела

На `Point Light Torch` в RomanLevel добавлен компонент **Roman Torch Light**:

| Параметр | Значение | Что меняет |
| --- | ---: | --- |
| Steps | 4 | Число интервалов яркости света; между ними резкие переходы. |
| Pixel Height | 163 | Высота сетки именно освещения. Меньше значение — крупнее световые пиксели. |
| Strength | 1 | Сила эффекта. 0 или отключение компонента возвращает обычный плавный свет. |

Цвет, Intensity и Range задаются в обычном компоненте Light. Сохранён зелёный цвет пользователя. Hard Shadows используют разрешение 512 на грань кубической карты теней. Параметры `RomanDream.mat` и Volume не менялись; их grain/bloom по-прежнему влияют на конечный кадр.

`RomanTorchSurface.shadergraph` сохраняет исходную текстуру, её масштаб/смещение, цвет, metallic и smoothness материалов окружения. `RomanTorchWater.shadergraph` — отдельная версия текущего водного графа с той же обработкой факела. Копии материалов в `TorchMaterials` назначены только объектам RomanLevel. При редактировании общего водного графа изменения нужно перенести также в эту версию.

Узел Custom Function в этих двух графах вызывает `RomanTorchLighting.hlsl`: вычисляет обычный вклад конкретного Point Light через URP, вычитает его и добавляет ступенчатый вклад через знаковую поправку в Emission. Свет и тени выбираются на сетке экрана; цвет текстур не постеризуется этим узлом. Остальные источники и окружающее освещение остаются в штатном расчёте URP. Функция сохраняет тени и исключает удвоение света. В обычном Preview поправка равна нулю; смотреть её нужно в Scene/Game View.

Ограничения прототипа: один назначенный realtime Point Light, Forward+/Forward с попиксельным освещением, metallic Lit без Clear Coat, DBuffer-декалей и baked shadow mask. Источник определяется по позиции; второй свет точно в той же позиции также попал бы под обработку. Фоновый туман с отдельным Unlit-шейдером не получает новую модель освещения. При отключении компонента оригинальная модель света восстанавливается; для полного удаления также верните исходные материалы через переопределения экземпляров в сцене.

## Свечение воды и тумана

Настраивается в **материале объекта**, в группе **Glow**:

- **Glow Enabled** — включает самосвечение.
- **Glow Color** — HDR-цвет; у воды это оттенок, умножающий её исходный цвет свечения (белый сохраняет палитру).
- **Glow Intensity** — яркость от 0 до 20. Для заметного эффекта начните с 2–5, затем подберите под сцену.

Основная вода использует `TorchMaterials/Torch_RomanWater.mat`; нижние водоёмы — `Env/RomanLevel/Water/RomanPool.mat`. Те же настройки есть у `RomanWaterfall.mat` и `RomanWaterTraces.mat`. Существующие значения яркости воды сохранены. Переключатель не отключает её преломление и освещение факелом.

Объёмный туман использует материалы `Env/Fog/RomanLevel_FogVolume*.mat` (пол, стены, потолок, труба). Новое свечение у них изначально выключено. Оно учитывает плотность тумана, края и перекрытие непрозрачной геометрией. Объект `roof animated fog` использует `Shaders/Water/Zowell_Water.mat`, у которого также появился выключенный по умолчанию Glow.

Мягкий ореол регулируется отдельно: `Global Volume` → `RomanDreamVolume` → **Bloom** → **Intensity**. В текущей настройке пользователя это 0; положительное значение включает ореол для достаточно ярких участков кадра. Самосвечение работает и при нулевом Bloom. Эмиссия не создаёт новый источник света для соседних стен.
